# Resources

게임이 실행 중에 읽는 파일을 두는 곳. 빌드하면 실행 파일 옆 `Resources/`로 복사된다.

| 파일 | 용도 | 없을 때 |
|---|---|---|
| `Gun.obj` | 총 모델 (내 총 + 다른 플레이어 총). 위치·법선·텍스처 좌표 | 상자 3개로 만든 임시 총 모양 |
| `Gun.mtl` | 재질. `map_Kd`로 텍스처 파일 이름을 알려 준다 | `Gun.png`를 찾는다 |
| `Gun.png` | 총 텍스처 (2048×2048) | 단색으로 그린다 |

- 지금 들어 있는 총은 Meshy AI로 만든 권총(`Meshy_AI_가장_기본이_되는_권총_20251205_texture_remesh_tri`)이다.
  파일 이름만 `Gun.*`로 바꾸고, OBJ의 `mtllib`와 MTL의 `map_Kd`를 새 이름으로 고쳤다.
- 크기·방향은 `Client/Render/GunModel.cpp`가 자동으로 맞춘다. 다른 모델로 바꿔도 그대로 쓸 수 있다.
  - Y가 위, X·Z 중 긴 축이 총열, 아래쪽(손잡이)이 몰린 반대쪽이 총구라고 보고 총구를 화면 정면으로 돌린다.
  - 화면에서의 크기·위치는 같은 파일의 `kGunLength`, `kGunPosition`으로 조정한다.
- 내 총은 텍스처 색 그대로, 다른 플레이어 총은 자리 색(파랑·초록·주황)을 반쯤 섞어 그린다.
- `.gitignore`의 `*.obj` 규칙에 걸리지 않게 이 폴더의 `.obj`는 예외 처리돼 있다.
